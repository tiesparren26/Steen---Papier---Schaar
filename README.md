# Steen Papier Schaar 🎮

Dit is een simpel spel dat ik heb gemaakt met HTML, CSS en JavaScript.

## 🕹️ Uitleg
Je speelt steen, papier, schaar tegen de computer.  
Je kiest zelf een optie en de computer kiest willekeurig.  
Daarna wordt bepaald wie er wint.

## ✅ Functionaliteiten
- Spelen tegen de computer
- Willekeurige keuzes met Math.random
- Score systeem (player vs computer)
- Kleuren bij winst/verlies
- Oneindig doorspelen
- Reset knop

## 🛠️ Technieken
- HTML (structuur)
- CSS (opmaak en styling)
- JavaScript (logica)
- Functions
- querySelectorAll
- switch statements
