# Steen Papier Schaar

Dit project bevat 2 versies van het spel.

## 📂 Versies

### v1
De eerste versie van het spel.
- Basis functionaliteit
- 3 aparte buttons met eigen code
- Simpele logica

### v2
De verbeterde versie van het spel.
- Minder dubbele code
- Gebruik van functions
- Gebruik van querySelectorAll
- Gebruik van switch statements
- Nettere en betere code

## 🎮 Wat doet het spel?
Je speelt steen, papier, schaar tegen de computer.
De computer kiest willekeurig en je ziet wie er wint.
Er wordt een score bijgehouden.
